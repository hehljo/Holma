# Internationalisierung (i18n) / Internationalization

Holma unterstützt mehrere Sprachen sowohl im Frontend als auch im Backend. / Holma supports multiple languages in both frontend and backend.

## Unterstützte Sprachen / Supported Languages

- 🇬🇧 **English (en)** - Default
- 🇩🇪 **Deutsch (de)** - German

## Frontend i18n

### Technologie / Technology

- **react-i18next**: React-Integration für i18next
- **i18next**: Internationalisierungs-Framework
- **i18next-browser-languagedetector**: Automatische Spracherkennung

### Sprachumschaltung / Language Switching

Die Sprache kann über den Sprachumschalter in der Seitenleiste (im Layout) oder auf der Login-Seite geändert werden. Die ausgewählte Sprache wird im localStorage gespeichert und bei jedem Besuch automatisch geladen.

The language can be changed via the language switcher in the sidebar (in Layout) or on the login page. The selected language is stored in localStorage and automatically loaded on each visit.

### Übersetzungsdateien / Translation Files

```
frontend/src/locales/
├── en/
│   └── translation.json  # Englische Übersetzungen
└── de/
    └── translation.json  # Deutsche Übersetzungen
```

### Neue Übersetzungen hinzufügen / Adding New Translations

1. Öffne die entsprechende Sprachdatei / Open the corresponding language file
2. Füge den neuen Schlüssel hinzu / Add the new key:

```json
{
  "dashboard": {
    "newKey": "New Text"
  }
}
```

3. Verwende den Schlüssel in der Komponente / Use the key in the component:

```jsx
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();
  return <div>{t('dashboard.newKey')}</div>;
}
```

### Interpolation

Texte mit Variablen / Texts with variables:

```json
{
  "history": {
    "page": "Seite {{current}} von {{total}}"
  }
}
```

```jsx
{t('history.page', { current: 1, total: 10 })}
// Output: "Seite 1 von 10"
```

## Backend i18n

### Technologie / Technology

- **Flask-Babel**: Flask-Erweiterung für Internationalisierung

### Spracherkennung / Language Detection

Das Backend erkennt die Sprache automatisch aus dem `Accept-Language` HTTP-Header. Der Frontend-API-Client sendet diesen Header automatisch mit der vom Benutzer gewählten Sprache.

The backend automatically detects the language from the `Accept-Language` HTTP header. The frontend API client automatically sends this header with the user's chosen language.

### Übersetzungsdateien / Translation Files

```
backend/app/translations/
├── en/LC_MESSAGES/
│   └── messages.po  # Englische Übersetzungen
└── de/LC_MESSAGES/
    └── messages.po  # Deutsche Übersetzungen
```

### Neue Übersetzungen hinzufügen / Adding New Translations

1. Füge die Nachricht in beiden `.po`-Dateien hinzu / Add the message in both `.po` files:

**en/LC_MESSAGES/messages.po:**
```
msgid "myapp.new_message"
msgstr "New message text"
```

**de/LC_MESSAGES/messages.po:**
```
msgid "myapp.new_message"
msgstr "Neue Nachricht"
```

2. Kompiliere die Übersetzungen / Compile the translations:

```bash
cd backend
pybabel compile -d app/translations
```

3. Verwende die Übersetzung im Code / Use the translation in code:

```python
from flask_babel import gettext as _

@app.route('/api/example')
def example():
    message = _('myapp.new_message')
    return {'message': message}
```

## Entwicklung / Development

### Neue Sprache hinzufügen / Adding a New Language

#### Frontend

1. Erstelle neues Verzeichnis / Create new directory:
   ```bash
   mkdir frontend/src/locales/fr
   ```

2. Kopiere und übersetze `translation.json` / Copy and translate:
   ```bash
   cp frontend/src/locales/en/translation.json frontend/src/locales/fr/
   # Übersetze die Werte / Translate the values
   ```

3. Importiere in `i18n.js` / Import in `i18n.js`:
   ```javascript
   import translationFR from './locales/fr/translation.json';

   const resources = {
     en: { translation: translationEN },
     de: { translation: translationDE },
     fr: { translation: translationFR }  // Neu
   };
   ```

4. Füge zur Sprachauswahl hinzu / Add to language selector

#### Backend

1. Initialisiere neue Sprache / Initialize new language:
   ```bash
   cd backend
   pybabel init -i messages.pot -d app/translations -l fr
   ```

2. Übersetze `fr/LC_MESSAGES/messages.po` / Translate the file

3. Kompiliere / Compile:
   ```bash
   pybabel compile -d app/translations
   ```

4. Aktualisiere `BABEL_SUPPORTED_LOCALES` in `app/__init__.py`

## Best Practices

### Do's ✅

- Verwende immer Übersetzungsschlüssel, nie hartkodierten Text / Always use translation keys, never hardcoded text
- Strukturiere Schlüssel hierarchisch (z.B. `dashboard.stats.totalBackups`) / Structure keys hierarchically
- Halte Übersetzungen konsistent / Keep translations consistent
- Teste alle Sprachen regelmäßig / Test all languages regularly

### Don'ts ❌

- Keine HTML in Übersetzungen / No HTML in translations
- Keine komplexe Logik in Übersetzungstexten / No complex logic in translation texts
- Vermeide zu lange Texte / Avoid too long texts
- Keine Vermischung von Sprachen / No mixing of languages

## Fehlerbehebung / Troubleshooting

### Frontend zeigt Übersetzungsschlüssel statt Text / Frontend shows translation keys

**Problem:** Text wird als `dashboard.title` anstelle von "Dashboard" angezeigt
**Lösung:**
1. Prüfe, ob die Übersetzungsdatei korrekt importiert ist / Check if translation file is imported correctly
2. Stelle sicher, dass der Schlüssel in der JSON existiert / Ensure the key exists in JSON
3. Prüfe Browser-Konsole auf Fehler / Check browser console for errors

### Backend-Übersetzungen funktionieren nicht / Backend translations don't work

**Problem:** API gibt immer englische Texte zurück
**Lösung:**
1. Prüfe `Accept-Language` Header in der Anfrage / Check header in request
2. Kompiliere die `.po`-Dateien neu / Recompile `.po` files:
   ```bash
   pybabel compile -d app/translations
   ```
3. Starte den Server neu / Restart the server

### Sprache wird nicht gespeichert / Language is not saved

**Problem:** Nach Reload ist die Sprache wieder auf Englisch
**Lösung:**
- Prüfe Browser localStorage / Check browser localStorage
- Stelle sicher, dass `i18next-browser-languagedetector` korrekt konfiguriert ist
